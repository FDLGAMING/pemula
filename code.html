💻 CODE LAB

A look inside the code behind Silent Bahar.
Built, tested, broken, fixed, and improved.

01 — ☰ HAMBURGER MENU

Kode ini membuat tombol ☰ yang digunakan untuk membuka side menu. JavaScript mendeteksi ketika tombol ditekan lalu menambahkan class active pada menu.

02 — ✕ CLOSE BUTTON

Bagian ini menangani tombol ✕. Saat tombol ditekan, class active dihapus sehingga menu kembali tertutup.

03 — 🔗 PAGE NAVIGATION

Atribut href digunakan untuk menghubungkan satu halaman HTML dengan halaman lainnya. Inilah yang membuat About, Music, Projects, dan halaman lainnya bisa berdiri sendiri.

04 — 🎵 MUSIC LISTEN BUTTON

Tombol LISTEN menggunakan link eksternal. Dengan target="_blank", lagu dibuka di tab baru sehingga halaman Music Silent Bahar tetap aman.

05 — 💻 PROJECT CARD

Struktur ini digunakan untuk membuat kartu project. Setiap project memiliki judul, deskripsi, dan teknologi yang digunakan sehingga portfolio mudah dibaca.

06 — 📱 BUILT ON ANDROID

Project ini bukan hanya tentang hasil akhir. Silent Bahar juga menjadi catatan perjalanan belajar programming dan web development dari perangkat mobile.
